# รหัสวิฃา  BSCCS304 (ภาคการศึกษาที่ 1/69)

# ฟีเจอร์การทำงาน (Feature)
1. เครื่องคิดเลขนี้ทำงานผ่าน Commandline(Terminal)
2. มีฟังก์ชั่นทางคณิตศาสตร์เบื้องต้นและขั้นสูงดังนี้ :
    2.1 + การบวก (Addition)
    2.2 - การลบ (Subtraction)
    2.3 * การคูณ ()
    2.4 / การหาร ()
